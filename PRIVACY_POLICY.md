# Política de Privacidade — Rota Lucro

**Última atualização: 18 de agosto de 2026**

O **Rota Lucro** é um aplicativo de apoio financeiro e operacional para motoristas de aplicativo. Esta Política de Privacidade explica como o app trata os dados informados pelo usuário.

## 1. Dados registrados no aplicativo

O Rota Lucro pode armazenar no próprio aparelho informações inseridas pelo usuário, como valores de corridas, quilômetros rodados, horas trabalhadas, metas, despesas, receitas, custos de combustível, manutenção e histórico de jornadas.

Esses dados são usados para gerar cálculos, relatórios e indicadores dentro do aplicativo. **O Rota Lucro não exige criação de conta e não envia esses registros financeiros para um banco de dados próprio.**

## 2. Permissões do Android

A versão oficial do Rota Lucro para Android solicita apenas:

- acesso à internet, necessário para carregar o conteúdo do aplicativo;
- acesso ao estado da rede, necessário para identificar disponibilidade de conexão.

O aplicativo não solicita acesso à localização, contatos, SMS, câmera, microfone, arquivos pessoais ou Serviço de Acessibilidade.

## 3. Armazenamento local e backup

Os registros do usuário são armazenados localmente no aparelho. O aplicativo oferece recursos de exportação/backup acionados manualmente pelo próprio usuário. O backup automático do Android está desativado para o aplicativo.

## 4. Dados técnicos de conexão

Para carregar o conteúdo online do Rota Lucro, a infraestrutura de hospedagem pode processar dados técnicos necessários à entrega e segurança do serviço, como endereço IP, data e hora da requisição, cabeçalhos de rede e identificação do navegador/WebView. Esses dados técnicos não são usados pelo Rota Lucro para criar perfis de publicidade comportamental.

## 5. Publicidade e venda de dados

O Rota Lucro não contém SDK de anúncios na versão atual e não vende os dados financeiros inseridos pelo usuário.

## 6. Compartilhamento

O Rota Lucro não compartilha os registros financeiros inseridos no aplicativo com anunciantes ou corretores de dados. Informações técnicas de conexão podem ser processadas pelos provedores de infraestrutura estritamente para operação, segurança e entrega do serviço.

## 7. Retenção e exclusão

Como os registros do Rota Lucro ficam localmente no aparelho, o usuário pode removê-los usando a opção de limpar dados do aplicativo, desinstalando o aplicativo ou apagando os registros dentro do próprio Rota Lucro quando essa opção estiver disponível.

O aplicativo não possui conta de usuário na versão atual. Portanto, não existe cadastro em servidor que precise ser excluído separadamente.

## 8. Segurança

O aplicativo utiliza conexão HTTPS para carregar seu conteúdo e bloqueia tráfego HTTP não criptografado na versão Android. Nenhum sistema é totalmente imune a riscos, mas buscamos reduzir a coleta de dados e limitar as permissões ao mínimo necessário.

## 9. Crianças e adolescentes

O Rota Lucro é destinado a motoristas e não foi desenvolvido para crianças. A publicação na Google Play deve ser configurada para público adulto.

## 10. Alterações desta política

Esta política pode ser atualizada quando o aplicativo receber novos recursos ou quando houver mudanças relevantes nas práticas de dados. A data da última atualização será indicada no início deste documento.
